# My Favorite Series: Stranger Things

## Overview
**Stranger Things** is a *sci-fi horror series* created by the Duffer Brothers.  
It is set in the 1980s and follows a group of kids who encounter supernatural events in their small town.

> “Friends don’t lie.” — Eleven


### Main Characters
1. Eleven  
2. Mike Wheeler  
3. Dustin Henderson  
4. Lucas Sinclair  
5. Will Byers


### Things I Like About It
- The 1980s retro style  
- Great storyline and mystery  
- Strong friendship between characters  
- Cool music and effects
